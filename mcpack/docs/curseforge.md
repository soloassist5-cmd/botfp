# Установка в CurseForge App

CurseForge App импортирует сборки из **zip** (внутри — `manifest.json`), а не
из `.mrpack`. Для него есть свой файл:

```
ls-city-life-1.0.0-curseforge.zip
```

Скачать — на сайте сборки, кнопка «Для CurseForge · zip» в окне скачивания
(или в архиве сборки: `dist\ls-city-life-1.0.0-curseforge.zip`).

**Распаковывать его не нужно** — CurseForge берёт zip целиком.

## 1. Импорт

1. Открой CurseForge App → **Minecraft** → **Create Custom Profile**.
2. Внизу окна нажми **Import** (в некоторых версиях — ссылка «Import a
   previously created profile»).
3. Выбери `ls-city-life-1.0.0-curseforge.zip`.
4. Появится профиль **LS City Life**: Forge 1.20.1-47.4.23 ставится сам, все
   моды CurseForge скачивает со своих страниц (64 мода, около 300 МБ). Ещё
   два файла лежат прямо в zip: самописный мод `citylife` и Memory Leak Fix
   (его нет в каталоге CurseForge, лицензия LGPL разрешает класть файл в
   сборку). Город `Los Santos` разворачивается в `saves` вместе с конфигами.

Установщик и команды не нужны.

## 2. Java и память

В профиле: три точки → **Profile Options** (или **Settings → Java & Memory**).

- **Java 17.** Не 21: на 21 Forge 1.20.1 работает нестабильно. CurseForge
  обычно ставит нужную Java сам. Если в списке только 21, поставь
  [Adoptium Temurin 17](https://adoptium.net/temurin/releases/?version=17)
  и выбери её.
- **Память:** 6 ГБ (8 ГБ, если в компьютере 16 ГБ и больше).

## 3. Запуск

**Play** → в списке одиночных миров уже будет **Los Santos**. Жители
расставятся сами: через пару секунд после входа появится сообщение
«Город заселён: NPC 177».

Если нужно вернуть всех заново (например, кого-то убили), есть команда:

```
/function citylife:npc/spawn_all
```

## Обновление сборки

Скачай новый `ls-city-life-1.0.0-curseforge.zip` и импортируй его ещё раз:
CurseForge создаст свежий профиль. Свой мир перед этим скопируй из
`saves` старого профиля (три точки → **Open Folder**) в новый.

## Если импорт не проходит

- Сообщение вида «Invalid file» обычно значит, что выбран не тот файл:
  `.mrpack` или архив сборки `ls-city-life-1.0.0.zip` CurseForge не
  импортирует — нужен именно `…-curseforge.zip`.
- Если какой-то мод не скачался (CurseForge показывает ошибку загрузки),
  нажми в профиле три точки → **Repair** или просто **Play** ещё раз —
  он докачает недостающее.

### Запасной путь — установщик

Если CurseForge по какой-то причине не может скачать моды, профиль можно
залить установщиком из архива `ls-city-life-1.0.0.zip`:

1. Создай профиль руками: **Create Custom Profile** → Minecraft **1.20.1** →
   Modloader **Forge**, версия **47.4.23**.
2. Распакуй архив сборки и запусти **`УСТАНОВИТЬ.bat`**. Он сам найдёт
   профили CurseForge и предложит тот, в названии которого есть «City»;
   Enter — и он скачает моды, сверит SHA-512, положит `citylife`, конфиги
   и город.

Если оборвётся — запусти `УСТАНОВИТЬ.bat` ещё раз: докачает только
недостающее.

## Что дальше

- Телефон открывается правым кликом по нему в руке.
- `/work` — подработка, раз в 5 минут.
- `/phonehelp` — рецепты телефона, замков и отмычки.
- Свободные участки помечены табличкой «ПРОДАЁТСЯ УЧАСТОК».
- **F10** — справочник клавиш.

Описание сборки целиком — в файле `docs/overview.md`.
