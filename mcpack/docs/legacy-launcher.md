# Установка на Legacy Launcher, TLauncher и другие лаунчеры без лицензии

Сборка целиком работает в офлайн-режиме: ни один мод не обращается к серверам
Mojang. Единственное, что может не работать на пиратке, — отображение скинов,
но от него в паке ничего не зависит.

## 1. Поставь Java 17

Forge 1.20.1 требует именно Java 17. На Java 21 он запускается, но падает на
части модов.

- Windows: [Adoptium Temurin 17 (JDK, x64, .msi)](https://adoptium.net/temurin/releases/?version=17)
- Проверить: в командной строке `java -version` должно показать `17.x`

Если в системе несколько версий Java, в лаунчере в настройках версии укажи путь
к `javaw.exe` от Temurin 17 вручную.

## 2. Установи Forge 1.20.1-47.4.23

В Legacy Launcher и TLauncher Forge ставится из самого лаунчера:

1. Создай новую конфигурацию (профиль) игры.
2. В списке версий выбери `1.20.1` → `Forge 47.4.23`
   (в TLauncher это отдельная строка «Forge 1.20.1»).
3. Запусти один раз «пустой» Forge, чтобы лаунчер докачал библиотеки, и выйди
   из игры. Так ты убедишься, что Forge рабочий, до того как добавятся 58 модов.

Если нужной версии Forge в списке нет, скачай установщик с
[официального сайта Forge](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)
(кнопка **Installer**, версия 47.4.23), запусти, выбери **Install client** и
путь к папке игры — лаунчер увидит версию после перезапуска.

## 3. Укажи отдельную папку игры

Не ставь сборку в общий `.minecraft`: 58 модов перемешаются с твоими другими
мирами и модами. Сделай отдельный каталог, например:

```
C:\Games\ls-city-life
```

В Legacy Launcher: настройки конфигурации → «Директория игры» (game directory) →
указать этот путь. В TLauncher: «Настройки версии» → «Папка игры».

## 4. Запусти установщик сборки

Открой PowerShell в папке `mcpack\install` и выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Target client -Path "C:\Games\ls-city-life"
```

Что он сделает:

- скачает 47 модов с Modrinth (клиентские + общие, ~342 МБ);
- сверит SHA-512 каждого файла и перекачает битые;
- скопирует самописный мод `citylife` из `mods-local`;
- разложит конфиги и KubeJS-скрипты;
- распакует мир в `saves\los-santos`.

Повторный запуск докачивает только недостающее. Ключ `-Clean` дополнительно
удаляет из `mods` посторонние jar-файлы, `-WithOptional` добавляет шейдеры
(Oculus), `-NoWorld` пропускает распаковку мира.

Linux и macOS:

```bash
./install.sh --target client --path ~/.minecraft-ls-city
```

## 5. Выдели память

6 ГБ рекомендованно, 4 ГБ минимум. В настройках конфигурации лаунчера найди
аргументы JVM и поставь:

```
-Xmx6G -Xms2G
```

Не выделяй больше половины оперативки компьютера: остальное нужно системе,
иначе игра начнёт тормозить именно из-за этого.

## 6. Первый запуск

Первый запуск дольше обычного (KubeJS и Distant Horizons прогревают кэш).
Дальше:

1. Зайди в мир **Los Santos** из списка одиночных миров.
2. Ты появишься на тротуаре у автовокзала, рядом — таблички с подсказками.
3. В инвентаре сразу будет телефон, немного монет и книга-гид.
4. Один раз выполни в чате команду, чтобы расставить жителей города:
   ```
   /function citylife:npc/spawn_all
   ```
   Повторный вызов убирает старых NPC и ставит их заново — так можно починить
   город, если кого-то случайно убили.

## Если что-то не запускается

| Симптом | Причина и что делать |
|---|---|
| Игра закрывается сразу, в логе `UnsupportedClassVersionError` | Java не 17. Укажи путь к Temurin 17 в настройках версии. |
| `Missing or unsupported mandatory dependencies` | Не все моды докачались. Запусти установщик снова — он докачает недостающее. |
| Вылет с `OutOfMemoryError` | Мало памяти. Поставь `-Xmx6G`. |
| Чёрный экран с шейдерами | Отключи Oculus или выбери другой шейдерпак: Distant Horizons дружит не со всеми. |
| Мир не появился в списке | Установщик не нашёл архив мира. Распакуй `world/los-santos.zip` в `saves` вручную. |
