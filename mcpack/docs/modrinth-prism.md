# Установка в Modrinth App, Prism Launcher, MultiMC и ATLauncher

**Это самый короткий путь: один файл, импорт, Play.** Установщики, командная
строка и ручное копирование не нужны.

Файл — `dist/ls-city-life-1.0.0.mrpack` (он же лежит кнопкой на сайте).
Внутри: ссылки на все моды с хэшами, конфиги, KubeJS-скрипты, **готовый город
в `saves/los-santos`** и **самописный мод `citylife`**. Forge и сами моды
лаунчер скачивает сам с авторских страниц и сверяет хэши.

## Modrinth App

1. **Add instance → From file** → выбери `ls-city-life-1.0.0.mrpack`.
2. Дождись, пока скачаются Forge 1.20.1-47.4.23 и 56 модов.
3. В настройках инстанса выдели 6 ГБ и убедись, что выбрана Java 17.

## Prism Launcher / MultiMC

1. **Add Instance → Import from zip** → укажи `.mrpack` (Prism понимает этот
   формат напрямую; MultiMC — начиная со сборок с поддержкой Modrinth).
2. Настройки инстанса → **Java**: путь к Java 17, память `-Xmx6G`.
3. Настройки инстанса → **Settings → Java arguments**, если нужно поменять флаги.

## ATLauncher

**Add Pack → Import → Modrinth pack** и выбери `.mrpack`.

## Мир и самописный мод уже внутри

Отдельно ничего копировать не нужно: город лежит в `overrides/saves/los-santos`,
мод `citylife` — в `overrides/mods`, и лаунчер раскладывает их при импорте.
Мир появится в списке одиночных сразу после первого запуска, а 174 жителя
расставятся сами при первом входе.

Если пак ставится поверх старого инстанса, в котором мир уже был, лаунчер
существующую папку `saves/los-santos` не перезапишет — старый город останется
как есть.

## Шейдеры

Oculus помечен как необязательный и в `.mrpack` не входит: он конфликтует с
Distant Horizons на части шейдерпаков. Если хочешь шейдеры — поставь
[Oculus](https://modrinth.com/mod/oculus) вручную и уменьши дистанцию
Distant Horizons до 64.
