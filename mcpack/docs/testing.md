# Чек-лист проверки в игре

Что проверено автоматически (и чем):

| Что | Чем |
|---|---|
| Версии 58 модов, ссылки, размеры, sha1/sha512 | `build/resolve_mods.py` |
| Совместимость модов: диапазоны из `mods.toml`, включая jar-in-jar | `build/check_deps.py` |
| Установка клиента и сервера, сверка хэшей, докачка, `--clean` | запуск `install.sh` и `install.ps1` |
| Загрузка самописного мода, регистрация, создание конфига | выделенный сервер |
| Загрузка всех 48 серверных модов вместе | выделенный сервер, 57 датапаков, без FATAL |
| Формат мира: 19 контрольных точек, биомы, таблички | `world/generator/verify_world.py` |
| Поиск паков оружия TaCZ | лог сервера: найдено 2 пака |
| Умный замок, камера SecurityCraft, банкомат, верстак TaCZ ставятся | `setblock` на сервере |
| Функции датапака грузятся и выполняются | `function citylife:npc/spawn_01` → 25 команд |
| NPC-торговцы сохраняют заданный ассортимент | `data get entity … Offers` |

Что **нельзя** проверить без живого клиента и нужно пройти руками:

## Клиент

- [ ] Игра запускается, в главном меню нет экрана с ошибками модов
- [ ] FPS в центре города приемлемый (ориентир: 60 на GTX 1650 без шейдеров,
      прорисовка 12)
- [ ] Distant Horizons дорисовывает силуэт города издалека
- [ ] Русский язык в интерфейсе телефона и подсказках предметов

## Телефон

- [ ] Правый клик открывает меню из 6 приложений
- [ ] «Контакты» показывают других игроков и расстояние
- [ ] «Сообщения» доходят до выбранного контакта
- [ ] «Банк» показывает баланс; перевод уходит и приходит
- [ ] «Карта» показывает координаты; метка добавляется и удаляется
- [ ] «112» рассылает вызов с координатами
- [ ] Приложения работают и на сервере, и в одиночной игре

## Умные замки

- [ ] Замок ставится на стену рядом с дверью и слушает правый клик
- [ ] Владелец открывает, посторонний получает «Заперто»
- [ ] Клик телефоном по замку привязывает его к приложению «Умный дом»
- [ ] Из «Умного дома» замок открывается на расстоянии до 64 блоков
- [ ] Выдача доступа контакту работает
- [ ] Код доступа ставится владельцем и пускает по вводу
- [ ] Отмычка иногда вскрывает, при провале звучит тревога и владелец
      получает сообщение
- [ ] Журнал доступа показывает последние события

## Город

- [ ] Появление на тротуаре у автовокзала, таблички читаются
- [ ] `/function citylife:npc/spawn_all` расставляет 125 NPC
- [ ] У торговцев в ТЦ есть ассортимент и торговля проходит за монеты
- [ ] Свободные участки видны по табличкам «ПРОДАЁТСЯ УЧАСТОК»

- [ ] В городе над землёй не спавнятся мобы, под землёй спавнятся
- [ ] Метро: вагонетка едет от станции к станции

## Мультиплеер

- [ ] Друзья заходят по адресу Radmin VPN
- [ ] Голосовой чат работает (клавиша `V` → соединение установлено)
- [ ] Белый список пускает только своих
- [ ] Сообщения и переводы между игроками доходят
- [ ] Сервер держит 4+ игроков без просадок TPS

## Если нашлась проблема

Сообщи, что именно и на каком шаге: почти всё в сборке собирается скриптами,
поэтому правка обычно означает поменять одну строку в `pack.toml`,
`plan.py` или `gen_datapack.py` и перегенерировать.

## Что в логах выглядит страшно, но нормально

| Строка в логе | Что это |
|---|---|
| `MTSERROR: Welcome to MTS VERSION: 24.0.0` и десятки `MTSERROR: Attempted to parse the OBJ model ...` | Immersive Vehicles пишет в лог всё, включая приветствие, уровнем ERROR. Сообщения про модели пуль и красок относятся к содержимому официального пака и на машины не влияют |
| `Found loot table element validation problem ... lightmanscurrency:chest/village/...` | Lightman's Currency ссылается на структуры деревень из мода, которого в паке нет. Ни на что не влияет |
| `Failed to read script file: elitex:sp_m1903_reload_logic_backup` | Резервный скрипт внутри пака оружия, оружие работает |
| `Plugin ... does not have required mod gamestages loaded, skipping` | KubeJS сообщает, что необязательная интеграция не нужна |
| `Initial datapack load took 11 s` | Первая загрузка датапаков с 58 модами и правда долгая; дальше быстрее |
| `Mod file ... is missing mods.toml file` про `fmlcore`, `javafmllanguage` и т.п. | Внутренние библиотеки Forge, так и должно быть |
