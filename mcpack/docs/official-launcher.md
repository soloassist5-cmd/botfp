# Официальный Minecraft Launcher

Официальный лаунчер Mojang/Microsoft не умеет импортировать сборки: ни
`.mrpack`, ни zip он не открывает. Поэтому для него есть отдельный архив
`ls-city-life-1.0.0-official.zip` с установщиком, который делает то же, что
Prism или Modrinth делают при импорте.

## Что понадобится

- Windows 10 или 11 и официальный Minecraft Launcher (обычный или из
  Microsoft Store) с купленной Minecraft Java Edition.
- 6 ГБ памяти для игры и около 4 ГБ на диске.
- Java отдельно ставить не нужно: установщик берёт ту, что встроена в лаунчер.

## Установка

1. Запусти официальный лаунчер, войди в аккаунт и закрой его. Это нужно один
   раз: лаунчер создаёт файл профилей, в который установщик добавит сборку.
2. Скачай `ls-city-life-1.0.0-official.zip` и распакуй **целиком** в любую
   папку (не запускай из окна архива — установщик не увидит свои файлы).
3. Двойной клик по `УСТАНОВИТЬ-ОФИЦИАЛЬНЫЙ-ЛАУНЧЕР.bat`. Установщик:
   - ставит Forge 47.4.23 для Minecraft 1.20.1 прямо в лаунчер;
   - скачивает 63 мода (~290 МБ) с авторских страниц и сверяет SHA-512;
   - раскладывает конфиги, мод `citylife` и город в отдельную папку
     `%APPDATA%\.minecraft-ls-city` — твои обычные миры и версии не трогаются;
   - добавляет в лаунчер профиль **LS City Life**: версия
     `1.20.1-forge-47.4.23`, эта папка игры и 6 ГБ памяти.
4. Открой лаунчер. Слева от кнопки «Играть» выбери **LS City Life** и нажми
   «Играть». Первый запуск Forge идёт 2–5 минут — это нормально.
5. Мир **Los Santos** — в «Одиночной игре». При первом входе выдадут телефон,
   SIM-карту, деньги и книгу-гид, а по городу расставятся жители.

## Если что-то пошло не так

| Сообщение | Что сделать |
|---|---|
| «Не найдены данные официального лаунчера» | Запусти лаунчер один раз, войди в аккаунт, закрой и запусти `.bat` снова |
| «Не нашёл Java» | Запусти в лаунчере ванильную 1.20.1 один раз (он скачает свою Java) или поставь Adoptium Temurin 17 |
| «Forge не удалось поставить автоматически» | Запусти показанный установщиком `forge-…-installer.jar` двойным кликом → Install client → OK, потом `.bat` ещё раз |
| Профиля «LS City Life» нет в списке | Перезапусти лаунчер: он читает профили только при старте |
| Мало памяти, игра вылетает | В лаунчере: Установки → LS City Life → Дополнительно → аргументы JVM, поменяй `-Xmx6G` |

Повторный запуск `.bat` безопасен: он докачает только недостающие моды,
не перезапишет уже сохранённый мир и обновит профиль. Прежний файл профилей
сохраняется рядом как `launcher_profiles.json.ls-city-backup`.

## Удаление

Удалить папку `%APPDATA%\.minecraft-ls-city`, а в лаунчере — установку
«LS City Life» (Установки → … → Удалить). Forge можно оставить или удалить
папку `versions\1.20.1-forge-47.4.23` из `%APPDATA%\.minecraft`.
