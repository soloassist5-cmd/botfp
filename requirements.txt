# Ядро бота (склад, выдача, панель, доктор, бэкап) работает на одной
# стандартной библиотеке — здесь пусто намеренно.
#
# Для связи с FunPay нужна библиотека FunPayAPI. Она не опубликована в PyPI и
# живёт форками на GitHub, поэтому ставится отдельно: указывать git-ссылку
# здесь значит ронять сборку на хостинге, если форк окажется недоступен
# (git спросит логин, а в билдере его некому ввести).
#
# Поставьте тот форк, к которому у вас есть доступ:
#   pip install "FunPayAPI @ git+https://github.com/<владелец>/<форк>.git"
#
# Без неё бот поднимется и будет работать во всём, кроме `botfp run`:
# склад, панель Telegram, doctor и backup доступны.
